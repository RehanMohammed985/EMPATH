EMPATH: do emotions change how AI agents change their minds?

The main idea. The base framework (Talekar & Jhala 2025) simulates 4 LLM agents with fixed MBTI personalities debating a topic while a judge scores every message from −1 to +1. Their agents reason but never feel. Real people in arguments get angry, anxious, and invested, and that shapes who persuades whom. The DEBATE benchmark (2025) showed LLM agent groups reach consensus unnaturally fast compared to 2,832 real humans. EMPATH tests one candidate explanation: missing emotion.

How. We give each agent an emotional state, computed each turn by appraising the message it just heard (does it attack my position? is it aimed at me? how forceful?), grounded in appraisal theory from psychology (Lazarus, Scherer). Emotion builds, decays, spreads between agents, and colors how each personality argues. Then we measure what changes: convergence speed, polarization, side-switching, and whether emotional contagion predicts persuasion.

OFFbaseline, no emotion (the original framework)
ONfull dynamic emotion via appraisal
FROZENemotion set once, never updates
RANDOMemotion changes randomly each turn
